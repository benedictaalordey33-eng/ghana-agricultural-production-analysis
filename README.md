# Ghana Agricultural Production Analysis (1961–2024)

## Project Overview
This project analyses the agricultural production trends of six selected crops in Ghana from 1961 to 2024 using data obtained from the FAOSTAT database.

The aim is to explore changes in crop production, harvested area and average yield over the study period using data analysis and visualization tools.

## Crops Analysed
- Cassava, fresh
- Cocoa beans
- Maize (corn)
- Plantains and cooking bananas
- Yam
- Rice

## Tools Used
- **Microsoft Excel:** Data inspection and preparation.
- **Microsoft Power BI:** Data analysis, visualization and dashboard development.

## Analysis Performed
- Production comparison by crop.
- Production trends over time.
- Harvested area comparison.
- Average yield comparison.

## Key Findings
- Cassava recorded the highest cumulative production among the selected crops.
- Cocoa beans recorded the highest cumulative harvested area.
- Cassava recorded the highest average yield.
